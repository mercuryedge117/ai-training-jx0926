## 事实链：原文 → Map → Reduce

> 选一个具体事实（数字 / 时间 / 状态 / 负责人），追踪它在三个阶段分别是怎么写的。

- 原文：09:57 Erin：按用户 ID 去重后，受影响用户为 430 位；涉及 512 个订单，其中部分用户多次重试。请求数、用户数、订单数是三个不同口径，不要相加。10:06 Erin：512 个订单中，398 个已在重试后支付成功，114 个尚未成功。这个状态截至 10:05，后续可能变化。不能把 114 个订单写成 114 位用户。
